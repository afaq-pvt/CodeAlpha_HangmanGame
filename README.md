Hangman Word Guessing Game

A simple command-line Hangman game built with Python as part of my Python programming internship practice.

Features

Random word selection
Letter guessing
Input validation
Detection of repeated guesses
Six incorrect guesses allowed
Score calculation
Win and game-over messages
Play-again option

Requirements

Python 3.x

How to Run

1. Install Python 3 if it is not already installed.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Run the following command in the terminal:
   
   python hangman.py

How to Play

1. Select Start Game from the menu.
2. Guess one letter at a time.
3. Correct guesses reveal letters in the hidden word.
4. You lose a life for each incorrect guess.
5. Guess the word before using all six incorrect guesses.
6. Choose whether to play again.
